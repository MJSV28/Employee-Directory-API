# Employee Directory API

A Spring Boot REST API for managing employee information with CRUD operations.

## Features
- Add new employees
- Retrieve employee details
- Update employee information
- Delete employees
- Search employees by name

## Technologies Used
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- REST API
- Maven

## Purpose
Developed to understand REST API development, database integration, and employee management using Spring Boot.
